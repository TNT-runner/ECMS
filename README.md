# 元件仓库 · 个人离线版

**当前版本：V1.0.0**

元件仓库（Component Desk）是一款用于管理电子元件资料、存放位置和库存数量的桌面软件。适合个人电子制作、开发调试和实验室元件整理，支持从建立元件资料到入库、领用、盘点和备份的完整流程。

软件采用 Python、PySide6 / Qt Widgets 和 SQLite 开发，数据保存在本机，日常使用无需联网、注册账户或部署数据库服务器。工程提供 Windows 单文件 exe，可直接双击运行。

- [更新公告](更新公告.md)：查看各版本新增、优化、修复与使用说明。
- [CSV 导入示例](Doc/批量导入示例.csv)：参考批量新增元件的文件格式。
- [源码说明](Source/README.md)：查看更详细的参数规则和开发说明。

## 快速开始

1. 打开工程中的 `Exe` 文件夹，双击 `元件仓库.exe`。无需另外安装 Python。
2. 点击左侧“库位管理”，建立实际存放位置，例如 `A柜 · 03格`。
3. 点击“新增元件”，选择类别，填写带 `*` 的必填参数并保存。
4. 选中刚新增的元件，点击“入库”，选择库位并填写本次增加数量。
5. 后续取料使用“领用”；清点后校正库存使用“盘点”。

新增元件时只建立资料，初始库存为 0；库存数量通过入库操作添加。第一次普通启动显示空库存属于正常情况。

详细教程请用浏览器打开 [Doc/使用说明.html](Doc/使用说明.html)。手册已内嵌截图，支持离线阅读、目录跳转、图片放大和打印。

## 主要功能

### 元件资料与分类参数

- 支持 18 类电子元件，每个类别提供对应的规格字段。
- 支持新增、编辑和移除元件资料；可记录名称、型号、封装、厂家与工作温度等信息。
- 电源管理芯片区分 DCDC、LDO 和 PMU；LDO 进一步区分固定输出和可调输出。
- 电池管理芯片、晶振、二极管等可根据具体类型显示适用参数。
- 带预设的可编辑输入框提供下拉箭头，也允许输入自定义值。
- 支持阻值、容值、感值、频率等数值与单位分开录入，并进行校验与换算。

支持的类别：

| 类别 | 类别 | 类别 |
| --- | --- | --- |
| 贴片电容 | 贴片电阻 | 主控芯片 |
| 电源管理芯片 | 协议收发芯片 | 电池管理芯片 |
| 电感 | TVS管 | 二极管 |
| 晶振 | MOS管 | 共模电感 |
| 三极管 | 磁珠 | 连接器 |
| 运算放大器 | 逻辑芯片 | 存储芯片 |

### 库存与库位

- 支持入库、领用和盘点，自动更新库存并记录变动。
- 同一元件可分放在多个库位，总库存为各库位数量之和。
- 领用数量不能超过所选库位的库存；盘点填写实物最终数量，自动记录差额。
- 库位管理支持新增、重命名、搜索、筛选空库位和删除空库位。
- 顶部显示元件种类、库存总数量、库存不足数量和库位使用情况。

### 查找与追溯

- 按名称、型号、厂家、参数、封装、备注及库位搜索，支持多个关键词组合。
- 按类别、封装、库位和库存不足状态筛选，支持列表排序。
- 详情页显示完整参数、库存及库位分布，可打开已关联的照片和 PDF 手册。
- 出入库记录保留时间、元件、库位、操作类型、变动数量、操作后余额及备注。

### 数据整理与备份

- 支持 CSV 导出与批量新增导入；导入前校验全部内容，通过后统一保存。
- 支持 ZIP 完整备份与恢复，包含数据库、库存历史和已有附件。
- 恢复前自动保存当前数据的备份，便于回退。
- 支持在设置中迁移到独立的空数据目录，并记住下次启动位置。
- 提供独立演示模式，方便体验界面与库存流程。

## 数据保存与使用说明

程序文件与库存数据分开保存。实际位置请在软件左下角“设置 / 数据目录”中查看。

| 项目 | Windows 默认位置或说明 |
| --- | --- |
| 个人库存 | `%LOCALAPPDATA%\ComponentDesk` |
| 演示库存 | `%LOCALAPPDATA%\ComponentDeskDemo` |
| 目录设置 | `%LOCALAPPDATA%\ComponentDeskSettings\settings.json` |
| 库存数据库 | 当前数据目录中的 `inventory.sqlite3` |
| 已有附件 | 当前数据目录中的 `attachments` 文件夹 |
| 默认备份 | 当前数据目录中的 `backups` 文件夹，也可另选保存位置 |

- **换电脑或完整迁移：** 在旧电脑创建 ZIP 备份，复制程序和备份到新电脑，再从 ZIP 恢复。只复制 exe 不会带走库存。
- **CSV 与 ZIP 用途不同：** CSV 用于资料整理和批量新增，不含历史与附件；完整保留库存请使用 ZIP 备份。
- **CSV 只新增：** 不覆盖已有元件 ID；重复导入 ID 留空的资料会产生新的元件条目。
- **移除元件：** 会删除该元件的资料、各库位库存和全部出入库记录；整理前建议先备份。
- **库存不足：** 总库存小于预警数量时提示不足；预警为 0 时不启用。当前界面未提供直接修改预警数量的输入框，可在 CSV 新增资料时设置。
- **附件：** 当前详情支持打开已有附件；新增 / 编辑表单尚未提供上传入口。

## 从源码运行

当前已验证的开发环境为 Windows、Python 3.13 和 PySide6 6.11.2，运行依赖以 `Source/requirements.txt` 为准。

在工程根目录打开 PowerShell，首次配置时运行：

```powershell
cd .\Source
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

已有可用虚拟环境时，进入 `Source` 后直接执行最后一条命令；也可双击其中的 `start.bat`。

可选启动参数：

```powershell
# 使用独立演示库存；空演示库中会生成六条电容 / 电阻示例
.\.venv\Scripts\python.exe app.py --demo

# 本次启动使用指定数据目录；路径优先于已保存的目录设置
.\.venv\Scripts\python.exe app.py --data-dir "D:\电子元件数据"
```

打包后的 exe 同样支持 `--demo` 和 `--data-dir` 参数。

## 检查与打包

以下命令均在 `Source` 文件夹中执行。

运行自动化测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

执行界面检查并生成检查截图：

```powershell
.\.venv\Scripts\python.exe tests\smoke_ui.py
```

重新生成 Windows exe：

```powershell
.\build.ps1
```

打包脚本使用项目虚拟环境安装打包依赖、生成图标，并将单文件程序输出到工程根目录的 `Exe` 文件夹；中间文件位于 `Source/build`。打包文件不包含个人库存。
